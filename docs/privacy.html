Política de Privacidade — Clube Quinze

Data de vigência: 2026-01-31

Introdução

Nós, Clube Quinze, respeitamos sua privacidade. Esta página descreve quais dados coletamos, por que os coletamos e como você pode gerenciar suas informações.

Dados que coletamos

  • Dados fornecidos por você: nome, e‑mail, telefone, data de nascimento, foto de perfil, dados de pagamento quando aplicável.
  • Dados de uso: registros de acesso, interações no app.
  • Dados de dispositivo: token de notificação push, modelo do dispositivo, sistema operacional, versão do app.
  • Dados de mídia: imagens enviadas pelo usuário. O app pode solicitar acesso à câmera para tirar fotos e ao armazenamento para selecionar imagens.

Uso de Câmera

O app utiliza permissão de Câmera para permitir que você tire fotos (por exemplo, foto de perfil). As imagens só são acessadas mediante sua ação e consentimento. Se preferir, negue a permissão no dispositivo.

Finalidades

Usamos seus dados para autenticação; agendamento e gestão de atendimentos; envio de notificações (lembretes, cancelamentos); suporte e melhoria do serviço.

Compartilhamento

Podemos compartilhar dados com provedores de infraestrutura, serviços de push (Expo Push), processadores de pagamento e prestadores contratados, sempre sob contrato que proteja os dados.

Segurança e retenção

Transmitimos dados via HTTPS e adotamos medidas técnicas e organizacionais razoáveis. Conservamos dados pelo tempo necessário às finalidades descritas ou conforme obrigações legais.

Seus direitos

Você pode solicitar acesso, correção, exclusão, portabilidade ou limitação do tratamento dos seus dados. Para exercer, contate: privacy@clubequinzeapp.cloud

Substitua contatos e prazos por valores finais antes de publicar oficialmente.
